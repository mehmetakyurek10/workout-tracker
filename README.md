# Workout Tracker

Egzersiz, program ve antrenman takibi yapmak için geliştirilen web uygulaması.

## 🛠️ Kurulum

```bash
# Repoyu klonla
git clone <repo-url>
cd workout-tracker

# Bağımlılıkları yükle
npm install

# .env dosyasını oluştur (.env.example referans alınabilir)
cp .env.example .env

# Sunucuyu başlat
npm start
```
